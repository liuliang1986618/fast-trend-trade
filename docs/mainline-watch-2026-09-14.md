现行 T3 只看"是否上涨"，建议**增加方向条件**，避免在下跌趋势中把"资金流入"误认为启动：

```json
// settings.mainline.etf_confirm（拟新增）
"etf_confirm": {
  "chg20d_min": 8,              // 现规则：20日≥8%
  "or_60d_high": true,          // 现规则：或创60日新高
  "trend_guard": {              // 拟新增：方向闸
    "etf_ma20_required": true,  // ETF 须站上 20 日线
    "etf_chg60d_min": -10       // 且 60 日跌幅不得超过 -10%（深跌中的资金流入不计为印证）
  }
}
```

**影响面**：若启用，今日的算力主线 T3 仍为 ✗（无变化），但**未来在深跌板块中出现资金流入时，不会因 ①成立就自动判"刚起步"**，
而是降级为人判——这与 §0 的"半机器半人"定位一致。
