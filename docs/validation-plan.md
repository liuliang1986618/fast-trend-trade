## 0. 为什么需要它（当前风险敞口）

系统有 60+ 参数，但验证只有**航运单线 45 天回放（n=1）**，且那是"教科书式主线"
（催化清晰 + 量价齐升），**不能代表全部市况**。因此当前参数不是"已校准"，而是"**未证伪**"。

## 2. 参数块级失效信号（§2.2，已落入配置）

| 参数块 | 失效信号（可观测量化阈值） | 重校动作 |
|---|---|---|
| `probe` 探测层 | 滚动 20 笔假信号率 > **0.70** | 重校探测层阈值 |
| `vcp` 蓄势分 | 蓄势分 ≥75 的票中突破成功率 < **0.40** | 调 `mature_score` 或 `windows` |
| `score_alert` L2 | 确认后 3 日内假信号率 > **0.50** | 收紧 `L2_start.vol_ratio_min` |
| `state_machine` | 单笔期望值连续 10 笔 < **0** | 冻结新开仓，全量复盘 |
| `etf_funnel` | 互证区信号 20 日后 ETF 回撤 >15% 的占比 > **0.50** | 收紧 `chg20d_max` |

**隔离回滚规则**：任一触发器命中 → **仅**该参数块回滚至上一版并记录原因，其他块不受影响。
（防止一次误判拖垮全系统；每次回滚在 `output/history.json` 或台账备注中留痕）

## 3. 纸面验收标准（§2.3，达标才固化参数）

| 维度 | 达标线 |
|---|---|
| 时长 | ≥**20 个连续交易日**，覆盖 ≥2 种市况 |
| 信号量 | 探测层累计 ≥15 笔；观察池状态机流转 ≥10 次（不足则延长） |
| 探测层 | 实际假信号率与 50% 基准偏差在 ±10pct 内 |
| L1/L2 | 航运两案例（08-10 假 / 09-07 真）在回放中**持续被正确拦截/放行** |
| 蓄势分 | 与实际突破的提前量分布，中位数 ≥**2 个交易日** |
| 期望值 | 纸面台账每笔记录 R 倍数，期末合并期望 **> 0** |
| 触发条款 | 任一参数块触发 §2 失效信号 → 该块回滚 v0.1 参数并记录原因 |

## 4. 执行方法（how-to）

### 4.1 数据来源（全部已有，无需新接口）

| 数据 | 来源 |
|---|---|
| 主线轮动时间线 + 阶段 + 趋势强度分序列 + 预警事件 | `output/history.json` 的 `rotation` |
| 观察池状态机流转 | `output/history.json` 的 `days[].watchlist` |
| K 线（ETF/个股，用于回溯验证） | `mcp__westock-mcp__data_kline`（支持 250 根） |
| 板块体检（跨日） | `rotation.sector_check` |

### 4.2 回放步骤（每个市况）

1. 选定时段（见 §1 候选），拉取锚定 ETF 与相关个股日 K
2. 用 `config/settings.json` 的 `tracking_score` 公式**重算**该时段趋势强度分（复现历史）
3. 按 `score_alert` 规则复跑 L1/L2 预警，记录每次触发的后续 3 日结果（确认/假信号）
4. 按状态机规则复跑观察池推进，记录每票的进出与最终结果
5. 统计 §3 的六项指标 → 写入 `docs/validation-log.md`（追加式）

### 4.3 留痕规范

- 每次回放在 `docs/validation-log.md` 追加一节：时段 / 市况 / 样本量 / 六项指标 / 结论（通过或触发哪个触发器）
- **禁止只记结论不记样本**——无样本的回放视为未做

## 5. 与自动化流水线的关系

- 每日 15:30 的自动化**继续正常产出**（不阻塞）
- `vcp` / `state_machine` / `etf_funnel` 三类触发器的样本**随每日运行自然积累**（突破成功率、期望值、ETF 回撤）
- 达到 §3 门槛后，本文件更新状态列并归档数据快照

## 6. v3.0 三池验证机制（2026-09-18/19 落地）

### 机制
- `track_pools.py` 每日运行：record（登记入池）+ price（价格序列）+ backfill（T+3/5/10/20 自动回填）
- 台账：history.json → pool_tracking.entries（append-only），首日已登记 51 条（A 8 / B 31 / C 12）

### 裁决规则（20 个交易日后）
- **B 池跑赢 A 池** → 原硬闸（PE 入口一票否决）在误伤，应放宽
- **B 池跑输 A 池** → 硬闸正确，维持现状
- 同口径对比：同日期入池、同 Horizon（T+3/5/10/20）、同基准（入池价）

### 与五维阈值校准的联动
- A 池五维评分（score_stable.py）阈值均为首版设定
- 20 日后按「各维分数与后续表现的相关性」校准权重
