# fast-trend-trade

> 双向锚定的 A 股趋势交易筛选框架：正向漏斗（个股→主线）× 反向漏斗（ETF→成分股）→ 共振矩阵 → 评分排序 → 条件单参数。

> ⚠️ **免责声明（请先阅读）**：本项目仅为量化筛选框架与个人研究工具，不构成任何投资建议。市场有风险，投资需谨慎。任何投资决策应结合个人风险承受能力、资金状况和投资目标独立判断。过往表现不预示未来收益。

> 🚧 **当前状态 v0.1**：数据源自动检测降级链、参数配置、策略手册已就绪；每日主循环 `run_daily.py` 开发中（见 `src/README.md` 路线图）。在此之前自检命令 `python3 src/check_provider.py` 可完整运行。

## 它解决什么问题

动量策略的经典困境是"确认即滞后"：等四维指标（均线多头/涨幅/量价/资金）全部确认，趋势已经走完一半。本框架的解法：

1. **三级火箭**：把探测器搬到资金链更早的环节（资金-价格背离 → 金叉/蓄势形态（回调变浅+缩量）→ 确认层改持有判据）
2. **双向锚定**：正向漏斗（个股→主线）与反向漏斗（趋势 ETF→成分股）交叉验证，双确认 = 共振，信号最强
3. **三物种隔离**：主线票 / 独立催化票 / 情绪票分仓分打法，判别错物种是亏损第一原因
4. **状态机执行**：R 单位仓位法 + 移动止盈，赚"看对时拿满、看错时亏小"的期望值

## 架构

```
每日盘后自动运行
├─ 正向漏斗：全市场个股 → 四维投票 → 五判据主线 → 位置分档 → 终池
├─ 反向漏斗：全市场 ETF → 主题去重 → 趋势 ETF 榜 → 成分股锚定
├─ 共振矩阵：主线✓ETF✓共振区 / ✗✓预热区 / ✓✗独立区 / ✗✗噪音区
├─ 蓄势形态打分：识别"回调变浅+缩量"的起涨前形态，输出突破价/认错价
├─ 百分制评分：硬闸一票否决 + 五维软分，≥80 优先 / 60-79 观察
└─ 产 出：日报 HTML + 驾驶舱（漏斗计量 + 矩阵 + 双翼明细 + 观察清单）
```

## 快速开始

```bash
git clone https://github.com/<you>/fast-trend-trade.git
cd fast-trend-trade
```

### 1. 配置数据源（可插拔）

本项目不绑定任何数据源。`src/providers/` 下实现统一接口即可：

```python
class DataProvider:
    def screen(self, expr: dict) -> list: ...     # 条件筛选（服务端优先）
    def kline(self, code: str, limit: int) -> DataFrame: ...  # OHLCV，列名 open/high/low/close/volume
    def fund_flow(self, code: str, days: int) -> dict: ...    # 主力资金
    def etf_rank(self, metric: str) -> list: ...  # ETF 排行
```

- **akshare**（推荐，免费开源）：参照 `src/providers/akshare_provider.py` 模板实现
- **自建/付费接口**：实现同一接口即可，筛选逻辑尽量下沉到服务端（避免全量下载——请求次数 ∝ 命令数而非股票数，这是本项目最重要的工程约束）

### 2. 调参

所有策略参数集中在 `config/settings.json`——改配置就是改策略，不要改代码。每个字段带 `_desc` 说明设计意图。

### 3. 运行

```bash
python3 src/run_daily.py --config config/settings.json
# 产物：output/daily/YYYY-MM-DD.html（日报）+ output/dashboard.html（驾驶舱）
# 建议每交易日 15:30 定时执行（crontab: 30 15 * * 1-5）
```

> 🚧 run_daily.py 开发中，上述命令将在 v0.2 可用。数据源部分现在即可自检：
> `python3 src/check_provider.py`

**私有配置**：机器相关参数（私有数据源路径等）放 `config/local.json`
（已 gitignore），启动时与 settings.json 深合并、本地键优先——开源仓库保持零机器路径。

### 4. 阅读

- `docs/strategy-handbook.html`：完整策略手册（物种判别 / 漏斗 / 三级火箭 / 状态机 / 评分 / 失效条件）
- 每日日报首屏：漏斗计量行（市场温度计）+ 共振矩阵（双向锚定）

## 核心原则（改代码前必读）

1. **服务端筛选，不全量下载**——请求次数 ∝ 筛选命令数（个位数），不是股票数（数千）
2. **评分用于分层不用于排序**——同层内不迷信分差；硬闸一票否决，不参与打分
3. **名单只出两类**——终产物 + 探测层头部；中间层只出数量（漏斗宽窄=市场温度计）
4. **简单系统严格执行 > 复杂系统半吊子执行**——每加一层算法，执行纪律就多一个被稀释的接口
5. **先跑两周再调权重**——用实盘记录回测校准，不要拟合历史
